# 🛒 Supermarket Management System

A complete desktop-based Supermarket Management System developed in Python to manage daily retail operations through a single integrated application.

The system handles inventory, sales, billing, customers, suppliers, purchases, returns, debts, and business reports, with role-based access for administrators, managers, and cashiers.

## 🚀 Key Features

- Inventory and Product Management
- Point of Sale (POS) System
- Shopping Cart and Checkout
- PDF Invoice Generation
- Customer and Debt Management
- Supplier Management
- Purchase Records
- Product Returns
- Role-Based Access Control
- Sales and Profit Dashboard
- Low-Stock Alerts
- Product Expiry Alerts
- Basic Sales Estimation
- CSV Data Export
- Automatic Database Backup
- User Activity Logs

## 🧠 Data Structures & Algorithms

The project applies several core data structures and algorithms:

- Linked List — shopping cart management
- Stack — undo operations
- Queue — cashier queue management
- Min Heap — expiry alerts and shortest cashier queue
- Max Heap — top-selling products
- Binary Search — product and barcode search
- Merge Sort — sorting products by expiry date

## 🛠️ Technologies

- SQLite

- Matplotlib

## 🎯 Project Purpose

This project was developed to combine software engineering, database management, graphical user interface development, and Data Structures & Algorithms in a practical retail management application.
